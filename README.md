# 🍽️ Restaurant Sales Dashboard

![Dashboard Preview](Dashboard.png)

## 📌 Overview
Interactive Excel dashboard created to analyze restaurant sales, customer ratings, delivery trends, and payment insights.

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards

## 📊 Key Insights
- Biryani had highest sales
- Delivery orders dominated
- UPI & Card mostly used
- Ratings were mostly 5 & 1
