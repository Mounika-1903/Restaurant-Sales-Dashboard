🍽️ Restaurant Sales Dashboard

📊 Overview

An interactive Restaurant Sales Dashboard created using Microsoft Excel to analyze sales performance, customer ratings, delivery trends, payment methods, and product/category performance.

The dashboard provides an interactive view of key business metrics and helps identify important sales and customer trends.

🎯 Objective

To analyze restaurant sales data and transform it into meaningful business insights using an interactive Excel dashboard.

🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards
- Data Cleaning
- Data Visualization

📌 Dashboard Features

- Total Sales
- Total Orders
- Average Order Value
- Total Quantity Sold
- Average Customer Rating
- Top-Selling Food Categories
- Peak Hour Sales Analysis
- Delivery Mode Analysis
- Revenue Trend
- Customer Rating Analysis
- Payment Method Analysis
- Quantity Sold Analysis
- Interactive Filters

📈 Key Insights

- Biryani generated the highest sales among the food categories.
- Delivery orders contributed significantly to the total orders.
- UPI and Card were the most frequently used payment methods.
- Customer ratings were concentrated around 5 and 1.
- The dashboard contains 600 total orders and 2,128 total quantity sold.
- Average customer rating was 2.945.
